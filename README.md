# あっち向いてほい（オンデバイス学習）

ブラウザの中だけで画像分類を学習させて、「あっち向いてほい」を遊ぶアプリ。
カメラ映像も学習データもサーバには送られません（推論・学習・保存すべてブラウザ内）。

## 使い方

```bash
npm install
npm run dev
```

ブラウザで <http://localhost:5173> を開き、カメラを許可してください。

> **WSL2 から使う場合**: Windows のブラウザで `http://localhost:5173` を開けばそのまま動きます。
> LAN の IP アドレス（`http://192.168.x.x:5173`）で開くと、ブラウザの制約でカメラが使えません。

### ① おしえる

各クラスのボタンを**押しっぱなし**にして、その方向を指さしている姿を 20〜40 枚ずつ撮ります。

- `上` `右` `下` `左` … 指さす方向（**画面に映った自分から見た**方向）
- `待機` … 何も指さしていない状態。**これを撮らないと常にどれかの方向に誤認識します**

学習データは IndexedDB に自動保存され、次に開いたときに復元されます。

### ② ためす

指さすとキャラクターがその方向に動きます。反応の悪い方向があれば ① で撮り足してください。

### ③ たたかう

じゃんけん → 勝った方が攻め → 「あっち向いて…ほい！」で画像認識。3 点先取。

- あなたが攻め: 指さした方向と CPU が向いた方向が**一致**したらあなたのポイント
- CPU が攻め: CPU が指さした方向と**違う**方向を向けばセーフ

## 仕組み

| 役割 | 実装 |
| --- | --- |
| 特徴抽出 | MobileNet v1 (alpha=0.25) を `conv_pw_13_relu` で打ち切り → 12544 次元 |
| 分類 | KNN（k=5、コサイン類似度）。サンプルを足した瞬間に反映される |
| 判定 | 「ほい！」の 500ms 間に集めた 6 枚前後を多数決 + 平均信頼度 0.6 以上 |
| 保存 | IndexedDB（特徴抽出器が変わったら自動で破棄） |

MobileNet の重みは `public/models/` に同梱しています（tfhub.dev の廃止で公式 URL が使えないため）。
そのおかげでオフラインでも動きます。

### ソース構成

```
src/
  ml/featureExtractor.ts   MobileNet の読み込みと前処理（中央切り出し・鏡反転・正規化）
  ml/classifier.ts         KNN のラッパ
  ml/storage.ts            IndexedDB への保存・復元
  ml/labels.ts             クラス定義
  game/judge.ts            複数フレームの多数決（純関数）
  game/stateMachine.ts     ゲーム進行
  ui/                      カメラ・学習パネル・信頼度バー・キャラクター・ゲーム画面
```

## テスト

```bash
npm test        # judge / stateMachine のユニットテスト
npm run build   # 型チェック + 本番ビルド
```

## うまく認識しないとき

- **学習した場所で遊ぶ**: MobileNet の特徴量は背景も見ています。場所や服装が変わったら撮り直してください。
- **はっきり大きく指さす**: 判定は信頼度 0.6 未満だと「判定できません」になります。
- **`待機` を多めに撮る**: 誤反応のほとんどは待機クラスの不足が原因です。

背景に左右されにくくするなら、`ml/featureExtractor.ts` を MediaPipe HandLandmarker の
landmark（21 点 × 3 座標）に差し替えるのが有効です（`FeatureExtractor` インターフェースを実装するだけ）。
